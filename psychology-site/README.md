# سایت نوبت‌دهی روانشناسی (React + Vite)

نسخهٔ React همان سایتی که ساختیم، با یک **فروشگاه کتاب و جزوه** اضافه‌شده.

## اجرا در VS Code
1. Node.js نسخهٔ ۱۸ یا بالاتر را نصب کن.
2. پوشه را در VS Code باز کن و در ترمینال (Ctrl+`) بزن:
   ```
   npm install
   npm run dev
   ```
3. آدرس `http://localhost:5173` را باز کن.

برای ساخت نسخهٔ نهایی: `npm run build` (خروجی در پوشهٔ `dist`).

## ساختار
```
src/
  main.jsx, App.jsx      ورودی و مسیرها (react-router)
  store.jsx              state سراسری + ذخیره در localStorage
  seed.js                داده‌های نمونه (دکترها، نوبت‌ها، محصولات)
  utils.js               ثابت‌ها و توابع کمکی (ساعت‌های آزاد، تاریخ، ...)
  styles.css
  components/            Avatar, Booking, SlotChips, FormDialog, ...
  pages/                 Home, DoctorPage, BlogPage, Shop, Cart, Track, Login
  panel/                 پنل مدیریت: Appointments, Doctors, Clients, Products, Tabs (گزارش، حساب‌ها، پیامک، سفارش‌ها)
```

## فروشگاه
- مشتری‌ها در `/shop` کتاب و جزوه را می‌بینند، فیلتر و جستجو می‌کنند و در `/cart` سفارش ثبت می‌کنند.
- محصول **چاپی** موجودی و آدرس ارسال دارد؛ محصول **دیجیتال** لینک دانلود دارد که بعد از «پرداخت‌شده» شدن سفارش در صفحهٔ پیگیری دیده می‌شود.
- مدیر کل همهٔ محصول‌ها و سفارش‌ها را مدیریت می‌کند؛ هر روانشناس فقط کتاب و جزوه‌های خودش را (تب «کتاب‌ها و جزوه‌ها»).

## چه چیزهایی هنوز نمونه است (برای استفادهٔ واقعی لازم است)
- **ذخیره‌سازی:** همه‌چیز در localStorage همین مرورگر است. برای چند کاربر باید بک‌اند و پایگاه داده اضافه شود (مثلاً Node + PostgreSQL، یا Supabase/Firebase).
- **ورود و دسترسی‌ها:** در حال حاضر فقط در مرورگر بررسی می‌شوند. نقش‌ها باید در سرور هم کنترل شوند و رمزها هش شوند.
- **پرداخت:** درگاه وصل نیست. جای اتصال در `src/pages/Cart.jsx` با `TODO` مشخص شده (مثلاً زرین‌پال).
- **پیامک:** فقط تنظیمات ذخیره می‌شود؛ ارسال واقعی به سرویس پیامکی و سرور نیاز دارد.
- **کد پیگیری مراجع:** باید با پیامک تأیید شود، وگرنه هر کس شمارهٔ مراجع را بداند می‌تواند تلاش کند.
- **تأیید پروانه:** مدیر کل دستی بررسی و تیک تأیید را می‌زند؛ استعلام خودکار نیست.
